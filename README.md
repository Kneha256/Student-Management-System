# Student Management System<br>

# Description<br>
This is a simple Python console-based Student Management System implemented using Procedural Programming.<br>
The program allows users to manage student records by adding new students, updating marks, searching for a student, and displaying all students with their marks.<br><br>

# Features
Add a new student along with marks<br>
Update the marks of an existing student (or add if not found)<br>
Search for a student by name<br>
Display all students and their marks<br>
Menu-driven interface for easy interaction<br><br>

# How to Use
Run the Python file student_management.py.<br>
Follow the on-screen menu instructions:<br>
Enter A to add a new student<br>
Ener B to update marks of a student<br>
Enter C to search for a student<br>
Enter D to display all student data<br>
Type STOP to exit the program<br><br>

# Notes
All student data is stored temporarily in a dictionary and will be lost once the program exits.<br>
Marks must be entered as integers.<br>
